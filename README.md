# 📚 Book Store Web Application

A modern, responsive, and feature‑rich **Book Store web application** built with **Next.js**.  
This project enables users to explore books, authenticate securely, and enjoy a smooth interactive browsing experience with elegant UI and animations.

---

## 🚀 Features

- 🔐 Secure user authentication powered by **Better Auth**  
- 👤 User sign up, sign in, and session management  
- 📖 Interactive book browsing interface  
- 📱 Fully responsive design across devices  
- 🎞️ Smooth animations with **Framer Motion**  
- 🔔 Toast notifications using **React Toastify**  
- 🎨 Modern UI components with **DaisyUI** and **HeroUI**  
- 🗄️ Integrated with **MongoDB** for data persistence  

---

## 🛠️ Tech Stack

### Frontend
- Next.js & React.js  
- Tailwind CSS  
- DaisyUI & HeroUI  
- React Icons  
- Framer Motion  
- React Toastify  

### Backend & Authentication
- Better Auth  
- MongoDB  

---

## 🎯 Project Purpose

This project was developed to practice and demonstrate:  
- Full‑stack development with Next.js  
- Implementation of a secure authentication system  
- Integration of MongoDB database  
- Designing modern, responsive UI layouts  
- Delivering an interactive and engaging user experience
